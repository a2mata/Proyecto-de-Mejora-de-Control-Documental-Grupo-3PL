# Proyecto-de-Mejora-de-Control-Documental-Grupo-3PL
El repositorio es un control documental que nos permita llevar el control de vencimientos de documentos legales de conductores y unidades de transportes que son requisito para la operación de distribución en Grupo  3PL
📄 El archivo README.md con la intención de transformación y el estado actual.

💡 La hipótesis de innovación (H-001) sobre la clasificación y control de vencimientos.

🧪 El experimento inicial (E-001) con la prueba piloto en la muestra documental.

📝 El registro formal de la decisión (D-001).

📖 La bitácora de aprendizajes (05-aprendizajes/bitacora.md) incluyendo la regla de notificación al correo institucional Vencimiento de documentos @grupo3pl.com.

💻 El Issue en GitHub con la tarea accionable para el equipo
